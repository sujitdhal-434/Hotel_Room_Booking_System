# 🏨 Hotel Room Booking System

A modern full-stack hotel room booking web application designed to simplify hotel reservations and management.  
This project provides a smooth booking experience for users along with a powerful admin management system.

---

## 🚀 Features

✨ User Authentication  
✨ Hotel Room Booking  
✨ Admin Dashboard  
✨ Booking Management  
✨ Responsive User Interface  
✨ Backend API Integration  
✨ Database Management  

---

## 🛠️ Tech Stack

### Frontend
- React.js
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
